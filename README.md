# Sorting Algorithm Visualizer (Terminal-Based)

A terminal-based sorting algorithm visualizer built with Python and `curses`.
It visually demonstrates how different sorting algorithms work step-by-step.

## ✨ Features
- Interactive terminal UI
- Multiple sorting algorithms
- Step-by-step visualization
- Quit mid-sort (q / ESC)
- Educational & beginner-friendly

## 📊 Algorithms Included
- Bubble Sort
- Quick Sort
- Merge Sort
- Heap Sort
- Bogo Sort (⚠️ for fun & chaos)
